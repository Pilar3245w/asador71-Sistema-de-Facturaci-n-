# Asador 71 - Sistema de facturación V1

Proyecto académico 1. Frontend en HTML, CSS, JavaScript (módulos ES) y Bootstrap 5,

con arquitectura MVC. Backend en PHP con base de datos MySQL.

## Cómo ejecutarlo
1. Instalar XAMPP y encender **Apache** y **MySQL**.

2. En phpMyAdmin (http://localhost/phpmyadmin), pestaña **SQL**, pegar y ejecutar
   el contenido de `database/asador71.sql`.

3. Copiar la carpeta `api/` a `C:\xampp\htdocs\` y renombrarla `asador71-api`.

4. Abrir este proyecto en VS Code y ejecutar `index.html` con **Live Server**.

## Funciones
Carta de platos, pedidos, boletas y facturas, IGV 10.5% (MYPE restaurantes 2026),
historial de ventas, anulación, informe y exportación a Excel.
